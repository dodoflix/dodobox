# Dodobox for Android TV and Android

A thin WebView app: it finds the Dodobox server on the home network by itself (mDNS), remembers it, and shows the same interface as the browser with remote-control navigation.

Open this folder in Android Studio and run it on a TV or phone. It is not built in CI and has not been tested on a device yet, so expect small build issues.

Without the app, Android TV can also use Cast: press the cast button in the player on a phone or laptop.
