# Code of conduct

Be respectful. Discuss the work, not the person. Harassment, personal attacks and discrimination are not tolerated in issues, pull requests or discussions.

Maintainers may edit or remove contributions that break this, and may block repeat offenders. To report a problem, use a [private security advisory](https://github.com/dodoflix/dodobox/security/advisories/new) and say it is a conduct report.

This policy is a short form of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
